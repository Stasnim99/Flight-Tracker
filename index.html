Glossary (hover to learn): Callsign The name a flight uses on the radio, e.g. "UAL123." It's usually the airline code plus a flight number, similar to a flight's "nickname" for air traffic control. ICAO24 A unique 24-bit ID permanently assigned to a specific physical aircraft (like a car's VIN number). Unlike a callsign, this never changes, even if the flight number does. Heading The compass direction the aircraft's nose is pointed, in degrees (0° = North, 90° = East, 180° = South, 270° = West). We rotate each plane icon on the map to match this.
